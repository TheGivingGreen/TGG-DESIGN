The heart-flag mark plus optional Playfair wordmark. Never redraw or recolour it.

```jsx
<Mark variant="cream" size={44} withWordmark onDark base="../.." />
```

- `full` on sand, `cream` on forest. There is no single-colour variant: the four layers are the mark, and flattening them to one colour loses the pin, the flag and the bunker. If a surface truly allows one colour only, set the brand name in Playfair Display 700 instead of the mark.
- `lockup` is the "Fore Good." arc version; give it room, it is not a nav mark.
- `base` is the relative path back to the design-system root so the file resolves from nested pages.
