Full-bleed duotone photo strip. Use it as punctuation between two argument sections.

```jsx
<PhotoStrip photos={[
  { src: 'assets/images/photos/strip1.webp', alt: 'Year One crowd at a Soulard bar' },
  { src: 'assets/images/photos/strip2.webp' },
  { src: 'assets/images/photos/strip3.webp' }
]} />
```

Gutters are 3px of shadow-ink, never wider. Two-up (`columns="1fr 1fr"`) is the other allowed rhythm.
