The nine-hole course list. Venue names in Anton, hole numbers in gold, 2px rules between.

```jsx
<CourseStack holes={[
  { hole: '01', venue: 'Social Bar & Grill', href: '#tickets' },
  { hole: '02', venue: "Ray's Sportshouse", href: '#tickets' }
]} />
```

Rows translate right by up to 80px on hover and the hole number flips to Flag red. Do not add icons or thumbnails; the typography is the design.
