# UI Kit: Pro Shop

Recreation of `pro-shop.html` in `TheGivingGreen/tgg-website`. The retail surface for event headwear.

## Screens

| File | Recreates |
| --- | --- |
| `index.html` | The Pro Shop page end to end |
| `ProShop.jsx` | Forest hero, notice strip, four alternating product bands, ceremonial close |
| `hats.js` | The four caps, with real copy, prices and SKUs from the source |

## What makes this surface different

The Pro Shop is the one place in the system where photography runs **full colour**. Everywhere else marketing imagery is duotone. Bands alternate sand and forest, and the art side swaps left to right with each band. Product art carries the only drop shadow in the system (`--shadow-product`).

## Not recreated

The Shopify storefront at `thegivinggreen.store` was not among the supplied sources, so no cart, product detail or checkout screens are included. The "Shop Now" buttons point at the real product URLs.
