# Slide Templates

Eight slide layouts for sponsorship and partnership decks, derived from the section structure of `sponsor.html` in `TheGivingGreen/tgg-website` (which presents the 2026 sponsorship deck as a scrolling page). The referenced PDF, `TGG_2026_Sponsorship_Deck.pdf`, was not in the repository, so the layouts follow the page's own numbered sections rather than a supplied deck file.

All slides are 1280x720.

| File | Layout | Use for |
| --- | --- | --- |
| `title.html` | Duotone photo, mark, Anton title, date stamp | Deck opener |
| `statement.html` | One enormous claim, Flag red on the last line | Concept, thesis |
| `proof.html` | Headline plus four stat tiles | Results, traction |
| `course.html` | Hole stack beside a Flag red claim card | The course, logistics |
| `scorecard.html` | The scorecard, centered | Rules, mechanics, pricing ladders |
| `tiers.html` | Three tier cards with accent rails | Sponsorship packages |
| `photo.html` | Full-bleed duotone, headline anchored bottom left | Section break, emotional beat |
| `close.html` | Contact close on forest | Final slide |

## Rules that carry over

- Section numbers (01 through 08) belong in the eyebrow. Number them.
- One Flag red moment per slide: a clause in the headline, a claim card, or the primary button. Never two.
- Photography is duotone. The only full-colour images in a deck are product renders and scorecard scans.
- Every dark slide closes with a gold left label and "Fore Good." bottom right. Drop the tagline on decks going to a single named recipient.
